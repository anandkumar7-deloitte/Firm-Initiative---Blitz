# RSVP broadcast request (urgent gap-fill, multiple skills/slots)

**When to use:** need to broadcast an urgent ask to a group/channel (not individual 1:1 pings) —
typically when multiple skills have gaps at once, or the eligible pool is already known to be a
named group.

**Before sending:** check the real eligible headcount per skill first (MasterPanel filtered by
Skill Approved = Y + Designation/level). If a skill's pool is very small relative to the ask (e.g.
asking for 4 slots against only 1–2 eligible people), say so to whoever's sending this — the
message alone won't close that gap; a message to all eligible individuals directly, or getting more
people approved for that skill, may be needed instead. Also double check near-identical skill
names aren't actually different population pools before filtering (see CLAUDE.md gotcha #8).
