# R2 → R1 rebalancing request

**When to use:** one level is overbooked for a skill while the other level has a gap for the same
skill (e.g. R2 excess + R1 gap), and you want to ask an R2 panelist to cover R1 instead this round.

---

Reaching out on behalf of the Blitz Team for the upcoming <<Weekday/Weekend>> Blitz
(<<date range>>).

Thanks for taking out some time to take interviews.

We currently have more R2 panelists than needed for **<<Skill>>**, while R1 has a gap for the same
skill. Would you be open to taking R1 interviews instead this round? Let us know if that's okay —
no need to refill the survey.

We'd really appreciate your support — thank you!

---

### Notes from real usage
- When someone agrees, record it in Panel Details' Comments column as something like
  `"(Manager) R2, confirmed to take R1 interview"`, and manually change their Level from R2 to
  R1 in that row — this is a manual override on top of the automated engine, not something the
  formulas compute on their own.
