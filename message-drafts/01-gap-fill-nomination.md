# Gap-fill nomination request

**When to use:** a drop-out has left a skill/level short of panelists, and you've identified a
pool of approved-but-not-yet-on-the-panel candidates (via MasterPanel + Skill Mapping) to invite.

**Before sending:** pull the real candidate list from MasterPanel (filter: Skill Approved = Y,
Designation matches the needed level, Location if relevant, not already in Panel Details/Final
Panels). If the event is same-day/next-day, message **all** candidates at once rather than
serially — don't wait for one "no" before trying the next person; see project history for why.

---

Hi **<<Name>>**,

Reaching on behalf of the Blitz Team regarding the **<<Event name>> — <<date>>, <<location>>
(<<In-Person/Virtual>>)**.

We've had a drop-out at the **<<R1/R2>> level for <<Skill>>**, and you're one of the panelists
we'd like to invite to step in and fill this slot.

Would you be interested in nominating yourself for this? <<If in-person: Please note this is an
in-person event in <<city>>, so travel arrangements would apply if you're based elsewhere.>>

Given we're already tight on time, it would help a lot to hear back from you **as soon as
possible** — even a quick yes/no works, and we can share further details once confirmed.

Thank you!

Regards,
Blitz Team

---

### Variant: multiple candidates for one opening

If asking several people for a single opening, add a line making that explicit so nobody is
surprised if someone else gets it first:

> Since this is a single opening, we'll confirm with whoever responds first.
